# Development Roadmap

## Phase 1 — Initial prototype
- [x] Spring Boot project and MySQL connectivity
- [x] Predefined service catalogue
- [x] Customer registration and validation
- [x] Token generation
- [x] Priority-based queue ordering with FIFO tie-breaking
- [x] Token lookup and position display
- [x] Basic waiting-time estimate

## Phase 2 — Queue administration
- [ ] Staff authentication and authorisation
- [ ] Staff dashboard
- [ ] Call-next operation
- [ ] Complete, skip, and cancel operations
- [ ] Concurrency protection for queue updates
- [ ] Staff-controlled priority verification

## Phase 3 — Extended functionality
- [ ] Service management interface
- [ ] Dedicated API response DTOs and API documentation
- [ ] Random public token lookup identifiers
- [ ] More robust waiting-time estimates based on measured service durations
- [ ] Expanded controller, security, integration, and concurrency tests
- [ ] Database migrations for deployment
